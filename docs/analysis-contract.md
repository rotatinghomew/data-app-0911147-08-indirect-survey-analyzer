# 分析资料与解释边界

## 问卷机制
rr 版本的机制以 force_yes、force_no、truth 概率给出，总和为一；平台不保存个人随机分支。rr_joint 的 latent_states 和 response_states 声明潜在联合状态及可观察随机编码，transition 每行是给定潜在状态的响应概率。业务资料只保存 coded_answer，不保存潜在状态。list 版本记录基础条目数 k、实验臂 added_sensitive 与回答 count；只保存计数，不保存选了哪一项。allocation 指明随机到人还是到班。

## 推断对象
主结果是声明总体中的经历边际比例、共同发生比例或组间差异，不输出任何个人敏感状态。不同机制可能只支持联合分布的部分函数，需要按用户提出的查询判断；不得默认经历独立来制造联合点估计。可估、部分识别和不可识别的表示，以及估计方法由开发者设计。分析需区分机制已知与机制失真假设，并保留估计边界、不确定性及版本可合并依据；未经解释的零一裁剪不是有效推断。无响应与聚类随机化须进入适用性判断。

## 现行实现

### 估计量
- **单项比例**：rr 用 `(q − force_yes) / truth` 反演，q 为观测回答均值；truth 为零时回答不含信息，判为不可识别。名单实验用实验臂与对照臂计数均值之差。两者都按声明分配层级计算方差；登记为学生级但版本与班级完全重合时，界面提示版本差异与班级差异不可分离。
- **共同经历比例**：只有保留随机化联合编码的 rr_joint 版本能给出。对潜在状态分布做 EM 最大似然，再按登记项目顺序把状态逐位 0/1 映射到查询项目。区间用轮廓似然（单自由度似然比），因为最大似然解常落在单纯形边界，Wald 正态区间不可靠；若登记为班级随机化则改用班级贝叶斯自助。联合版本同时给出 Pearson 拟合检验，自由度按边界解的非零潜在格数修正；检验不通过时该版本不提供点估计（状态为 `unidentified`），避免把与声明机制不符的编码当作可信结果。
- **群体差异**：先在每个版本内部相减，使同一版本的机制偏倚在差值中抵消，再按异质性检验决定是否跨版本合并；不会先把不同版本的比例平均后再相减。
- **无联合编码时**：只用两个边际给出 Fréchet 范围 `[max(0, Σp − (k−1)), min(p)]`，并明确标注这不是置信区间、不能用中点代替重叠比例。只有用户显式勾选独立性假设，才额外给出乘积点估计，且始终同时保留该范围。

### 版本合并
默认 `pooling=auto`：先做 Cochran Q 异质性检验。若各版本点估计不一致，结果标为 `heterogeneous` 且**不给出**合并点估计，只列出各版本。`pool=强制合并` 会合并但在结果中保留异质性提示；`none` 只按版本报告。若各版本在声明失真半径内的识别范围彼此不相交，界面明确指出，不制造一个虚假的共同范围。

### 假设
- `mechanism_error`：给声明转移/随机机制加总变差失真半径。rr 与 list 直接平移识别范围；rr_joint 用线性规划在半径内求该查询函数的最小/最大值。
- `nonresponse=bound`：用邀请数把未响应者按最不利情形计入，扩宽识别范围；组内未登记邀请数时明确说明界限不可用。
- `ceiling_floor=bound`：名单计数落在 0 或 k+1 边界时，按一个条目的最大移动放宽范围。
- `clustering=class`：即使登记为学生级也按班级聚类计算不确定性。
- `independence`：仅对缺失联合信息显式启用乘积，状态为 `assumption_based`。

### 状态含义
| 状态 | 含义 |
| --- | --- |
| `identified` | 按声明设计可点估计 |
| `partially_identified` | 只能给出范围，或估计落在边界/依赖失真半径 |
| `unidentified` | 设计不含该查询的信息 |
| `heterogeneous` | 版本点估计不一致，未自动合并 |
| `version_specific` | 按设置或层级不合并 |
| `assumption_based` | 仅在显式建模假设下可点估计 |

### 联合机制的拟合检验
对 rr_joint 版本，比较观测响应计数与最大似然潜在分布 `T^T π` 的 Pearson 检验。自由度按 `响应类别数 − 1 − (非零潜在格数 − 1)` 计算；边界解使非零格数减少，自由度相应减少。检验不通过（p<0.05）时，界面说明机制与计数不符，并把该版本判为不可点估计。观测比例偶尔低于转移矩阵的某类下限，在有限样本下可能只是抽样波动，界面只作提示，最终以拟合检验为准。

## 可核对资料
纯 truthful 的 rr 机制应退化为普通抽样比例；truth 为零时，回答没有提供敏感比例信息。名单实验中实验臂与对照臂的均值差有手算基准，但设计效应和顶底效应可能破坏解释。analysis_cases 提供只有两个边际机制而无联合信息、带联合编码、版本混合及计数越界输入；去掉唯一联合信息来源后，不应继续输出同等确定的共同发生比例。

具体检查（`tests/test_analysis.py`）：
- truthful_rr：单版本 rr 估计等于 0.4375，即样本比例。
- no_truth：truth=0 时单项与联合都判为不可识别。
- list_manual：均值差精确等于 0.5。
- marginals_without_joint：重叠比例状态为 `partially_identified`，Fréchet 范围为 `[0, 0.3644]`；启用独立性后为 `assumption_based`。
- 默认资料：去掉 joint-1 后，同一联合查询从有点估计变为不可识别，不会保留同等确定性。
- 默认资料中三个版本对 overload 的估计经 Q 检验不一致（p≈0.0001），因此默认不合并；强制合并会明确提示异质性。

## 已知限制
- 资料未登记遵从情况，无法识别直接作答或替换随机分支；估计按“机制如声明执行”解释。
- 班级名单是否完整未单独登记，回收缺口无法区分为班级整体缺失与个人未响应。
- rr_joint 的 `latent_states` 与 `response_states` 的位序是声明的一部分，不随数据重新估计；若登记顺序与设计不符，估计会错位。
- 轮廓似然区间在极少数边界配置下可能偏窄，页面同时给出识别范围供对照。
